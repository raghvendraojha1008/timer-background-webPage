# Icon Resources

You need to create the following icon files for your app:

## Required Icons:

### 1. **icon.ico** (Windows App Icon)
- Size: 256x256 pixels
- Format: ICO (multi-resolution recommended: 16, 32, 48, 256)
- Purpose: Main application icon shown in taskbar, shortcuts, file explorer

### 2. **tray-icon.png** (System Tray Icon)
- Size: 16x16 or 32x32 pixels
- Format: PNG with transparency
- Purpose: Small icon that appears in system tray

### 3. **icon.png** (General Purpose)
- Size: 512x512 pixels
- Format: PNG with transparency
- Purpose: Used for various UI elements and store listings

## How to Create Icons:

### Option 1: Online Tools
1. **Favicon.io** (https://favicon.io/) - Convert images to ICO
2. **CloudConvert** (https://cloudconvert.com/) - Convert PNG to ICO
3. **Canva** (https://www.canva.com/) - Design custom icons

### Option 2: Design Software
- **Figma** (Free) - Design and export
- **Adobe Illustrator** - Professional design
- **GIMP** (Free) - Create and export as ICO

## Design Tips:
- Use simple, recognizable designs
- Ensure good contrast for visibility
- Test at small sizes (16x16)
- Use your clock/timer theme colors
- Consider using a clock face or timer symbol

## For Microsoft Store:
You'll also need:
- **StoreLogo.png**: 50x50 pixels
- **Square44x44Logo.png**: 44x44 pixels
- **Square150x150Logo.png**: 150x150 pixels
- **Wide310x150Logo.png**: 310x150 pixels
- **Square310x310Logo.png**: 310x310 pixels (optional)

Place all Microsoft Store assets in this folder when preparing for submission.
